CRITICAL · Priority 95.0

North Korea-linked PolinRider campaign plants Python loader in over 7,600 GitHub repositories

US 85% · Europe 85% · MEA 85% · Other 85% · Global IT services 80% · Energy services 50% · Secure software delivery and DevSecOps 95% · SIEM, monitoring and detection engineering 60%

SafeDep reports that the PolinRider campaign has hidden a Python loader in thousands of GitHub repositories, inside small utils packages or conftest.py files. The loader runs when the file is imported. It reportedly gets its next step from blockchain transaction data. The activity has been linked to North Korea and may date back to February 2025.

Why it matters: A large-scale code supply-chain poisoning campaign on GitHub, a widely used platform, attributed to a nation-state.

Action: Check cloned or vendored GitHub code for suspicious conftest.py and utils modules. Pin dependencies and review them before use. Run untrusted code in sandboxes, and check the scope against SafeDep's indicators.

Detection assessment: Assessment: scan repositories for unexpected conftest.py or utils loaders. Watch developer endpoints for Python processes querying blockchain APIs. No rules were provided in the source.

Sources: The Hacker News

HIGH · Priority 75.0

US 75% · Europe 75% · MEA 75% · Other 75% · Telecommunications 60% · Global IT services 60% · Vulnerability and exposure management 85% · SIEM, monitoring and detection engineering 50%

A researcher has published details and a proof-of-concept for an unpatched Cacti flaw, called 4HTTP2SHELL/4HTTP2ROOT. Starting from guest access, it reaches command execution in four HTTP requests. No CVE has been assigned yet, and no exploitation in the wild has been reported.

Why it matters: An unpatched remote code execution flaw with a public PoC in a widely used monitoring tool, with no confirmed exploitation.

Action: Turn off Cacti guest access, restrict access to the Cacti interface to trusted networks, and apply a vendor patch once one is released. No exploitation has been confirmed so far.

Detection assessment: Assessment: watch for unusual guest-session HTTP requests to Cacti and for unexpected child processes started by the web server.
