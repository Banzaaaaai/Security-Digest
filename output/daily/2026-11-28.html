US Air Force Cloud One platform reportedly breached amid wave of federal attacks

Why it matters: Reported major breach at a US government/defense organization, which is a target industry in a target region. The report remains unconfirmed.

SAP is investigating a suspected breach in which unknown attackers got into its GitHub environment, potentially exposing source code. SAP has not said what was accessed or whether any customers are affected.

Why it matters: A major enterprise software vendor's development environment was breached. No tampering with software or impact on customers has been reported so far.

HIGH · Priority 75.75

Unpatched Cacti zero-day with public PoC allows unauthenticated remote code execution

US 75% · Europe 75% · MEA 75% · Other 75% · Telecommunications 60% · Global IT services 60% · Vulnerability and exposure management 90% · SIEM, monitoring and detection engineering 55%

A zero-day in the Cacti network monitoring platform has been publicly disclosed along with a proof-of-concept exploit. It lets unauthenticated attackers run commands on vulnerable servers, and no patch is available. The source does not report any in-the-wild exploitation.

Why it matters: Unauthenticated RCE with a public PoC and no patch; no exploitation reported.

Action: Find all Cacti instances, take them off the internet or restrict access to them, and apply the fix once it is released. Hunt for signs that the PoC has been used.

Detection assessment: Our assessment is that defenders should watch Cacti web logs for unusual requests and look for unexpected child processes started by the web server user.

Sources: BleepingComputer
