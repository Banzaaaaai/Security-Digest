CRITICAL · Priority 94.25

Cursor links trojanized Claude Code extension on its marketplace to key stolen in Fireworks AI breach

US 85% · Europe 85% · MEA 85% · Other 85% · Global IT services 80% · Energy services 50% · Secure software delivery and DevSecOps 90% · AI-assisted work and AI governance 85%

Cursor says an attacker used an access key issued to Fireworks AI, which was exposed in a breach at Fireworks. The incident ended with a trojanized version of the Claude Code extension on Cursor's extension marketplace. The full scope and number of affected users are not clear from the source.

Why it matters: A popular developer extension was compromised and distributed through a marketplace, which is a supply-chain compromise involving the Claude Code watch technology.

Action: List the Cursor and Claude Code extensions installed across your developer machines, then compare them with vendor guidance. Rotate any credentials exposed on endpoints that ran a suspect version.

Detection assessment: Our assessment is that monitoring which IDE extensions are installed and where developer endpoints connect would help, but the source gives no indicators.

CRITICAL · Priority 93.75

Cursor confirms breach enabled distribution of malicious Claude Code extension via its marketplace

US 85% · Europe 85% · MEA 85% · Other 85% · Global IT services 75% · Energy services 50% · Secure software delivery and DevSecOps 90% · AI-assisted work and AI governance 85%

Cursor confirmed a security breach in which attackers distributed a malicious Claude Code extension through its extension marketplace. According to the report, the attackers got in using credentials stolen from AI infrastructure provider Fireworks AI. The source does not say how many users installed the extension or what it did.

Why it matters: A popular developer-tool marketplace was compromised to push a malicious extension. This counts as a supply-chain compromise affecting developers worldwide.

Action: List the Cursor and Claude Code extensions installed across your organisation and remove any that look suspicious. Rotate secrets that are reachable from affected developer machines. Watch for vendor IOCs, since the full scope is still unclear.

Detection assessment: No detection rules were provided. Our assessment: check developer endpoints for unexpected extension installs and unusual outbound connections or credential access from IDE processes.

HIGH · Priority 70.0

CISA adds actively exploited UnrealIRCd command injection flaw CVE-2026-114713 to KEV

US 60% · Europe 55% · MEA 50% · Other 50% · Government 40% · Telecommunications 35% · Vulnerability and exposure management 80% · SIEM, monitoring and detection engineering 50%

CISA has added CVE-2026-114713 (CVSS 8.6) to its Known Exploited Vulnerabilities catalog after reports that attackers are exploiting it. The flaw affects UnrealIRCd, an open-source IRC server, and comes from improper neutralization of delimiters, which allows command injection at the server level. UnrealIRCd is a niche product in enterprise environments.

Why it matters: The flaw is in CISA KEV and is being actively exploited. UnrealIRCd is not widely deployed enterprise software, so this rates high rather than critical.

Action: Check whether any UnrealIRCd instances are running, including shadow IT. Patch them per vendor guidance and review the hosts for signs of compromise.

CVE-2026-114713 | KEV yes | EPSS 0.00508 | CVSS unknown

Detection assessment: The source links no detection rules. Assessment: watch IRC server hosts for unexpected child processes and outbound connections.
